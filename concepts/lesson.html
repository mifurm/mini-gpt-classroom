def decision_reward(case, action):
    validate_values(case)
    if len(case) != 3 or action not in [0, 1]:
        raise ValueError("Decisions require cost, benefit, budget and action 0 or 1.")
    cost, benefit, budget = case
    return 0 if action == 0 else benefit - cost if cost <= budget else -10

One supervised update

concept_models.py:191-199
def update(model, optimizer, loss):
    if not torch.isfinite(loss):
        raise RuntimeError("Nonfinite supervised training loss.")
    optimizer.zero_grad(set_to_none=True)
    loss.backward()
    norm = nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    if not torch.isfinite(norm):
        raise RuntimeError("Nonfinite supervised gradients.")
    optimizer.step()
  • D1: cross_entropy(policy(features), oracle_actions).
Speaker notes

Both families use this update. D1 supplies action cross-entropy; the GPT supplies response-token cross-entropy. Finite checks and gradient clipping surface failures.

Decision and reasoning models

An explicit two-step program

concept_models.py:54-62
def reasoning_example(values, scratchpad):
    validate_values(values)
    prompt = "cap(" + ",".join(map(str, values)) + ")="
    running, steps = values[0], []
    for index, value in enumerate(values[1:]):
        running = max(running, value) if index % 2 == 0 else min(running, value)
        steps.append(running)
    response = ",".join(map(str, steps if scratchpad else steps[-1:])) + "\n"
    return prompt, response
Speaker notes

The first running state is max(a,b); the second is min(that,c). Digits are visible program states, not hidden thoughts or natural-language rationalizations.

Shifted response-only supervision

concept_models.py:71-84
def response_batch(cases, scratchpad):
    if not cases:
        raise ValueError("A supervised batch cannot be empty.")
    examples = [reasoning_example(case, scratchpad) for case in cases]
    length = max(len(encode(prompt + response)) - 1 for prompt, response in examples)
    x = torch.zeros((len(cases), length), dtype=torch.long)
    y = torch.full_like(x, -100)
    for row, (prompt, response) in enumerate(examples):
        tokens = encode(prompt + response)
        x[row, :len(tokens) - 1] = torch.tensor(tokens[:-1])
        # The final prompt token predicts the first response token.
        start = len(encode(prompt)) - 1
        y[row, start:start + len(encode(response))] = torch.tensor(encode(response))
    return x, y
Speaker notes

Ignored targets remove prompt and padding loss. The final prompt byte predicts the first response byte. Causal attention prevents later padding from affecting earlier outputs.

Decision and reasoning models

Teacher forcing is not free generation

  • Training: correct previous response tokens; response-only loss.
  • Testing: greedy GPT.generate(top_k=1); stop scoring at first newline.
  • Verifier checks generated transitions, not teacher-forced predictions.
  • Malformed responses and missing steps count as failures.
Speaker notes

During training the correct first step is in the input when predicting the final answer. At test time only the prefix is supplied; all response tokens are generated.
