The whole plan

  1. Freeze public-domain data and held-out passages.
  2. Implement embeddings, causal attention, residual blocks.
  3. Train with next-byte cross-entropy.
  4. Compare five changes using the same held-out targets.
  5. Generate text, inspect failures, keep the best checkpoint.
Speaker notes: Start with PLAN.md. Ask students what evidence would establish that the model learns instead of just memorizing. We will show both held-out metrics and samples.

Bytes and honest splits

ids = list("Alice".encode("utf-8"))
# [65, 108, 105, 99, 101]
x = ids[:-1]  # A l i c
y = ids[1:]   # l i c e

Train 132,440 · validation 16,427 · test 16,428 bytes.

Contiguous 80/10/10 passages; discard 128 bytes at both boundaries. Never let a training window cross a split.

Speaker notes: Bytes avoid a tokenizer training subsystem and unknown tokens. They are not GPT-2 BPE: byte context and byte perplexity are not word/BPE context or perplexity. Unicode characters can span multiple bytes.

From tokens to logits

[B,T] byte IDs
    ↓ token embedding + learned positions
[B,T,C] hidden states
    ↓ decoder blocks × L
[B,T,C] final LayerNorm
    ↓ tied token-embedding projection
[B,T,256] next-byte logits

Final model: B = 32, T = 64, C = 128, L = 2, heads = 4.

Speaker notes: The output at position t predicts the byte after t. F.linear uses the same token embedding matrix; no independent output matrix is learned. Inspect model.py together and track tensor dimensions.

Causal multi-head attention

Q, K, V = linear(x).chunk(3, dim=-1)
scores = Q @ K.transpose(-2, -1) / sqrt(head_width)
scores[future_positions] = -infinity
weights = softmax(scores)
output = project(weights @ V)

Each head sees only its own position and the past. Four heads each use 32 features in the final model.

Speaker notes: Show the lower-triangular mask. Explain scaling by square root of head width. Changing future input bytes must leave all earlier logits exactly unchanged; our test checks this. Without this property training can cheat.

A GPT-2-style block

x = x + attention(layer_norm_1(x))
x = x + mlp(layer_norm_2(x))

mlp = Linear(C, 4*C) → GELU → Linear(4*C, C)

Pre-normalization, residual paths, bias-bearing projections, tanh-approximate GELU. Final LayerNorm follows the blocks.

Speaker notes: These are the structural choices in OpenAI's open-source src/model.py. nn.Linear expresses the reference's conv1d projection. Residual projection initialization is scaled by depth. We omit KV caching and large-scale training engineering, not the Transformer mechanism.

Learning: one visible training step

x, y = sample_shifted_windows(train_bytes)
optimizer.zero_grad(set_to_none=True)
logits, loss = model(x, y)
loss.backward()
clip_grad_norm_(model.parameters(), 1.0)
optimizer.step()

Cross-entropy = −log probability of the correct next byte. AdamW: LR 0.001, decay 0.01.

Speaker notes: All positions in each training window contribute to loss. Explain gradient clipping and batch 32. Contrast training with held-out evaluation: we score only each selected target's final logit, using its preceding context.

Limits students should understand

  • One OCR book; one seed; short, 64-byte context.
  • Training/validation gap and memorization risk.
  • Repeated validation selection; unequal training budgets.
  • No instruction following, reliable facts, or long-story reasoning.
  • Byte tokens replace BPE; no pretrained weights or KV cache.
Speaker notes: This is honest experimental evidence, not a claim of production readiness. Contiguous splits avoid window leakage but cannot remove recurring names and phrases within one book. More parameters and more training are not automatically better; use validation and preserve an untouched test.
