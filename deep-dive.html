    starts = torch.randint(len(data) - context, (batch_size,), generator=rng)

17 / 85
Architecture

Why LayerNorm and GELU are not optional details

  • LayerNorm(x) = gain·(x−μ)/√(variance+ε) + bias; statistics are across C.
  • GELU approximately gates x by the probability it exceeds a Gaussian threshold.
  • The residual path carries existing information and a direct gradient route.
  • Final LayerNorm precedes the tied vocabulary projection.

Our nn.LayerNorm default ε is 10⁻⁵; GELU uses approximate='tanh'.

Speaker notes

Contrast LayerNorm with BatchNorm: its behavior does not depend on another example in the minibatch. GELU is not ReLU; it retains a smooth negative-side response. These operations are preserved from the GPT-2 structural pattern.

Warm starts plus controlled depth growth

model.py:151-162 · grow_depth
def grow_depth(parent, layers):
    if layers < parent.config.layers:
        raise ValueError("Depth growth cannot remove existing blocks.")
    model = GPT(replace(parent.config, layers=layers)).to(parent.token.weight.device)
    state = model.state_dict()
    state.update(parent.state_dict())
    model.load_state_dict(state)
    # New residual branches start as identity, preserving the parent's inference.
    for block in model.blocks[parent.config.layers:]:
        nn.init.zeros_(block.attention.project.weight)
        nn.init.zeros_(block.mlp[2].weight)
    return model
Speaker notes

This is the entire helper. It only permits adding blocks. Existing state tensors are copied, then new attention and MLP output projection weights are zeroed. Their biases already initialize to zero. With dropout disabled, the new residual branches add zero, preserving the parent's inference function before training.

def document_batch(documents, context, rng, batch_size=32):
    if not documents or any(len(document) <= context for document in documents):
        raise ValueError("Each training document must contain a complete shifted window.")
    if len(documents) < 2:
        raise ValueError("Expanded training needs the original plus at least one new book.")
    weights = torch.tensor([0.5] + [0.5 / (len(documents) - 1)] * (len(documents) - 1))
    chosen = torch.multinomial(weights, batch_size, replacement=True, generator=rng)
    x = torch.empty((batch_size, context), dtype=torch.long)
    y = torch.empty_like(x)

P(original)=0.5; P(each new book)=0.5 / number_of_new_books.

Speaker notes

Rehearsal deliberately oversamples the small original document. It aims to reduce forgetting of the original style while sharing the rest of the windows across new works equally, not proportionally to their byte lengths.

Generation / decoder choices

Temperature and top-k do not change learned quality

  • Temperature τ scales logits: probabilities = softmax(logits / τ).
  • Lower τ sharpens probabilities; higher τ adds randomness.
  • Top-k suppresses all but the k highest-scoring byte logits.
  • Every recorded sample uses τ=0.8, k=40, 240 generated bytes, fixed seeds.

Reported loss/accuracy use raw model logits, not temperature or top-k filtering.

Speaker notes

Decoding can make samples look cleaner while leaving held-out predictive scores unchanged. Fixed seeds make a controlled qualitative comparison; they do not make one sample representative of all outputs. Invalid UTF-8 can be produced.
