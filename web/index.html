    04 / DIFFERENT KINDS OF MODELS
    Decisions, answers, and scratchpads.
    
      
    
      
    Each model uses 100 heldout synthetic input triples. These task accuracies are not comparable to next-byte prose accuracy. The answer-only control already solves the task: no accuracy advantage for reasoning is claimed. R1 fails the required format on unseen longer problems. This is supervised learning, not reinforcement learning or general-purpose reasoning.

    What this lab does not prove
    Single seeds, short byte contexts, repeated validation, OCR errors, and unequal compute limit generalization. Byte perplexity is not GPT-2 BPE perplexity. Better byte prediction is not coherent writing. Recorded experiments are preserved; this site neither retrains models nor serves a chatbot.
    Archive scans are marked public domain in the US. Check local rights before reuse, including Peter Pan-related UK provisions. Raw corpora and model checkpoints are not hosted here.
