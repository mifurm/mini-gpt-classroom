# Two classroom GPT versions

Both models were trained from scratch again on the same frozen public-domain Internet Archive OCR. The original final checkpoint, six-run report, and HTML/PDF deck remain unchanged. [PLAN_V2.md](PLAN_V2.md) explains the architectural changes and further improvements worth investigating.

| Version | Role | Blocks | Width / heads | Byte context | Dropout | Parameters | Updates / best checkpoint |
|---|---|---:|---:|---:|---:|---:|---:|
| v1 | Simplest teaching model | 2 | 128 / 4 | 64 | 0.0 | 437,760 | 1,800 / 1,800 |
| v2 | Extended teaching model | 3 | 128 / 4 | 128 | 0.1 | 644,224 | 3,600 / 2,600 |

V2 adds context, one decoder block, and dropout at embeddings, attention weights, attention residual output, and MLP output. Dropout is active only during training. Both versions retain GPT-2-style learned positions, pre-LayerNorm, explicit causal attention, 4x-width GELU MLPs, residual paths, and tied byte embeddings.

## Measured quality

| Version | Train loss | Sampled validation loss | Full validation loss | Reused test loss | Test bits/byte | Test byte PPL | Test accuracy |
|---|---:|---:|---:|---:|---:|---:|---:|
| v1 | 1.078 | 1.622 | 1.573 | 1.628 | 2.349 | 5.094 | 54.8% |
| v2 | 0.942 | 1.516 | 1.505 | 1.560 | 2.250 | 4.758 | 57.0% |

V2's selected checkpoint changes sampled validation loss by -6.5% and reused test loss by -4.2% relative to V1 (negative means lower/better). Accuracy is next-byte prediction, not answer correctness.

V2's best checkpoint is update 2,600, not the last update. Its final training checkpoint's validation loss was 1.575, versus 1.516 at the selected checkpoint. Additional training did not keep improving generalization.

Qualitatively, the first V2 sample contains longer recognizable phrases such as 'cried Tweedledee' and 'the King looked', but still starts 'She were said' and invents misspellings. Both models remain ungrammatical and lack story-level coherence. Dropout was intended to regularize; these bundled runs do not prove it reduced overfitting, and a substantial train/validation gap remains.

**Selection protocol:** same 1,024 distinct validation targets, checkpoint checks every 200 updates, same seed 42, optimizer, learning rate and clipping. Full validation scores cover 16,299 target bytes; test covers 16,300. Only sampled validation chooses the checkpoint. Each model uses its own context length.

**Test limitation:** the original test was previously reported during V1. It is a reused holdout, not a new independent final test. No V2 settings or checkpoint were chosen from the new test scores. Architecture, dropout, and compute changes are bundled; this is not a causal ablation or multi-seed benchmark.

## Training budget and equal-update comparison

| Version | Training bytes presented | Training seconds | Validation loss at 1,800 updates |
|---|---:|---:|---:|
| v1 | 3,686,400 | 25.4 | 1.622 |
| v2 | 14,745,600 | 198.9 | 1.547 |

The 1,800-update comparison removes the difference in update count, **not** the difference in compute: V2 has more blocks and processes twice as many bytes per update. Its full training run processes four times V1's bytes. Training seconds exclude sample generation and full validation/test scoring.

Exact original V1 weight reproduction after retraining: **True**. Original teaching artifact checksums were checked before/after training and again during report verification.

Environment: `{"python": "3.13.14", "torch": "2.13.0", "device": "cpu", "threads": 4}`.

## Choose either version

Use **V1** to introduce the smallest architecture and demonstrate the original results. Use **V2** for a second lesson on longer context, extra depth, regularization, and compute/quality tradeoffs. Neither is a chatbot or a reliable long-form writer.

```bash
cd /Users/michalfu/mini-gpt-classroom
python3 generate.py --version v1 --device cpu --prompt 'Alice said, "'
python3 generate.py --version v2 --device cpu --prompt 'Alice said, "'

# Reproduce both; preserves original artifacts/final.pt and first-study results.
python3 train_versions.py --device cpu
python3 report_versions.py
```

Checkpoints: `artifacts/versions/v1.pt`, `artifacts/versions/v2.pt`.
Raw results and learning curves: `artifacts/versions/comparison.json`, `v1.json`, `v2.json`, and the two `*_curve.jsonl` files.
